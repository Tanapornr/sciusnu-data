# SCiUS NU · Project Advisor

เว็บไซต์ค้นหาอาจารย์ที่ปรึกษาโครงงานอยู่ใน repository นี้ทั้งหมด ใช้ HTML/CSS/JavaScript ปกติ ไม่มีขั้นตอน build และไม่ต้องใช้ Google Apps Script

## เปิดเว็บไซต์

- Vercel: เชื่อม repository เลือก Framework Preset **Other** ไม่ต้องใส่ Build Command และใช้ Output Directory เป็น `.` (มี vercel.json กำหนดไว้แล้ว)
- GitHub Pages: ใช้ branch main และโฟลเดอร์ / (root)
- ทดสอบในเครื่อง: `node serve.cjs` แล้วเปิด http://127.0.0.1:4173

## หน้าต่าง ๆ

1. หน้าแรก: กลุ่มสาขาจากคอลัมน์ B ของชีต ข้อมูล ค้นหาได้ทั้งไทยและอังกฤษ
2. หน้ารายชื่อ: ชื่อจาก A และความเชี่ยวชาญ C–F แสดงเฉพาะช่องที่มีข้อมูล
3. หน้าประวัติ: อีเมล G โครงงาน TH/EN ตามคู่ H/I, J/K, L/M และตารางนัดหมายจากชีต ตารางเวลา จับคู่ด้วยชื่ออาจารย์ ไม่อิงลำดับแถว

ปุ่มบาร์ “ส่งอีเมลนัดหมาย” เปิดหน้าเขียนข้อความของ Outlook บน https://outlook.cloud.microsoft/mail/ พร้อมระบุอีเมลอาจารย์เป็นผู้รับ หากยังไม่เข้าสู่ระบบ Microsoft จะพาไปเข้าสู่ระบบก่อนและเก็บลิงก์หน้าเขียนข้อความไว้ ผู้ใช้เขียนข้อความ ตรวจ และส่งเอง ไม่มีการส่งอีเมลอัตโนมัติหรือจองคิว ตารางเวลาปัจจุบันเป็นวันพฤหัสบดี 13.00–16.00 น. ตามหัวชีต

ใช้โลโก้ SCiUS NU ที่ให้มา แสดงเนื้อหาที่ขนาด 110% ด้วย rem และยังใช้ layout ที่ยืดหยุ่นตามหน้าจอ ไม่มีเมนู หน้าแรก / เกี่ยวกับระบบ / ติดต่อเรา ในส่วนหัวหรือท้ายเว็บ

## ข้อมูล Google Sheets

แหล่งข้อมูล: https://docs.google.com/spreadsheets/d/1OWRw3riYGpDxgTim9HS0r_lEoJtB4cGckac4JwztcSE/edit

- `data.json` เป็นสำเนาข้อมูลล่าสุดจากชีตที่ให้มา เพื่อให้เว็บไซต์เปิดใช้งานได้ทันที
- เมื่อเปิดเว็บหรือกดโหลดข้อมูลใหม่ เว็บจะพยายามอ่านชีตต้นทางผ่าน Google Visualization API และเปลี่ยนเป็นข้อมูลสดเมื่ออ่านได้
- ปัจจุบันชีตเป็นส่วนตัว การอ่านสดจากเว็บไซต์สาธารณะจึงยังถูกปฏิเสธ เว็บจะแสดงข้อมูลสำรองและวันอัปเดตอย่างชัดเจน
- หากต้องการให้แก้ชีตแล้วเว็บไซต์เปลี่ยนตามทันที เจ้าของชีตต้องเปิดสิทธิ์อ่านผ่านลิงก์ หรือ publish ข้อมูลตามนโยบายของหน่วยงานเอง ไม่ต้องเปลี่ยนโค้ด Apps Script
- เมื่ออัปเดตสำเนา ให้คงโครงสร้าง `data`, `schedule`, `fetchedAt` ใน data.json
- ไม่มีรูปอาจารย์ในชีต จึงใช้ชื่อย่อแทน ภาพอาคารเป็น SVG กราฟิก

## โครงสร้างไฟล์

- index.html / styles.css: โครงหน้าและการแสดงผล รองรับขนาดหน้าจอต่าง ๆ
- app.js / core.js: เปลี่ยนหน้า ค้นหา แปลงข้อมูล แสดงตาราง และสร้างร่างอีเมล
- config.js: ชีตต้นทางและการอ่านข้อมูล
- data.json: ข้อมูลจากชีตสำหรับ fallback
- core.test.cjs: ตรวจการแปลงข้อมูลและการเข้ารหัสร่างอีเมล

ตรวจโค้ดด้วย `node --check app.js` และ `node core.test.cjs`
